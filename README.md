# 🚀 Ali Hooshangi Portfolio - Next.js 15

Welcome to **Ali Hooshangi Portfolio**, a modern and fully responsive portfolio project built with **Next.js 15**, TypeScript, TailwindCSS, Redux, and a collection of developer-friendly tools for high-performance and SEO-optimized websites.

> This project showcases my work, skills, and projects as a frontend developer and web designer.

---

## 🧰 Tech Stack

- ⚡ [Next.js 15](https://nextjs.org/) – React framework for production
- 🔷 [TypeScript](https://www.typescriptlang.org/) – Strongly typed JavaScript
- 🌈 [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework
- 🌙 [next-themes](https://github.com/pacocoursey/next-themes) – Dark/light theme support
- 🧠 [Redux Toolkit](https://redux-toolkit.js.org/) – Modern state management
- 🌐 [Axios](https://axios-http.com/) – HTTP client for API requests
- 🔧 [ESLint](https://eslint.org/) + [Prettier](https://prettier.io/) – Linting and code formatting
- 🐶 [Husky](https://typicode.github.io/husky) + [Lint-Staged](https://github.com/okonet/lint-staged) – Git hooks and pre-commit checks
- 🔍 [next-seo](https://github.com/garmeeh/next-seo) – SEO utilities
- 🧃 [React Hot Toast](https://react-hot-toast.com/) – Notifications and toasts
- 🎨 [React Icons](https://react-icons.github.io/react-icons/) – Icon components
- 💧 [Swiper](https://swiperjs.com/) – Carousel/slider UI component
- 🌐 [i18next](https://www.i18next.com/) – Internationalization (i18n)
- 🪄 [Zustand](https://zustand-demo.pmnd.rs/) & [redux-persist](https://github.com/rt2zz/redux-persist) – State persistence

---

## ✨ Features

- ✅ Modern Next.js 15 + TypeScript setup
- 📦 Feature-based architecture
- 🎯 SEO optimized (`next-seo`, `next-sitemap`)
- 📊 Fully responsive design with TailwindCSS
- 🧼 Linting & formatting with ESLint & Prettier
- 🐶 Git hooks via Husky + Lint-Staged
- 🧃 Notifications & toasts with React Hot Toast
- 🔁 Global API setup with Axios
- 🧠 Redux Toolkit + Zustand state management
- 🌍 i18n support ready
- 🎨 Swiper slider for projects and testimonials
- 🧱 Easily extendable for future projects or freelance work

---

## 🛠 Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/alihoushngi/ali-hooshangi-portfolio.git
cd ali-hooshangi
npm install
npm run dev
```
